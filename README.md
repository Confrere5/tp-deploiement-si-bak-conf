# TP — Déploiement d’un système d’information

Projet de supervision industrielle réalisé en binôme. L’application a pour objectif de lire des mesures d’automates en Modbus TCP, de les historiser et de les afficher sur un tableau de bord accessible depuis le réseau local.

Architecture prévue : frontend HTML/CSS/JavaScript servi par Nginx, API Node.js/Express et base MariaDB, orchestrés avec Docker Compose.
